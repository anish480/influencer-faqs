Admin mode

Edit and publish FAQs back to GitHub. No backend, no server — your edits commit straight to faqs.json.

First time? Generate a fine-grained token with the narrowest scope possible:
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Resource owner: the account that owns this repo. Repository access: Only select repositories → pick this one only.
  3. Permissions → Repository permissions → set Contents to Read and write. Leave everything else at No access.
  4. Set an expiry you're comfortable with (90 days is reasonable). Generate, copy the token, paste here.
The token is stored only in your browser's local storage. Anyone with access to your device can read it — sign out (or revoke the token in GitHub) when done.
